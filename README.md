# Dompet Mahasiswa

Website pengelolaan keuangan mahasiswa menggunakan HTML, CSS, JavaScript, Flask, dan SQLite.

## Menjalankan
1. Instal Python 3.10 atau lebih baru.
2. Buka terminal pada folder proyek.
3. Jalankan `python -m pip install -r requirements.txt`.
4. Jalankan `python app.py`.
5. Buka `http://127.0.0.1:5000` di browser.

File `database.db` dibuat otomatis saat aplikasi dijalankan. Chart.js memerlukan internet untuk memuat grafik. Aplikasi ini dirancang untuk demonstrasi lokal, belum memiliki login multi-pengguna atau pengaturan produksi.
